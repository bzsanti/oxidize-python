The `oxidize-pdf` Python package exposes PDF generation, reading and document operations through `oxidize_pdf`. These guides target **0.23.3**, which uses Rust core **5.5.5**.

Start with [installation and a complete example](/quickstart), then check [versions and limits](/scope).

The [repository](https://github.com/bzsanti/oxidize-python) contains additional examples and type stubs. The [published package](https://pypi.org/project/oxidize-pdf/0.23.3/) includes the native extension.

For documentation inside a coding assistant, see [Context7](/context7). The optional PDF-operation MCP server is a separate integration.
