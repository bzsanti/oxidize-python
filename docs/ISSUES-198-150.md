The tests use the real installed extension and MCP server. Raw catalog assertions
name every expected tool independently; they do not reuse advertised capabilities.
The actual SDK round trip validates behavior beyond discovery. Stdio process
arguments are fixed test paths/arguments, with no shell interpolation, and test
workspaces are temporary. Child processes are closed or killed on timeout.

The retry change follows option A in #150. It mitigates transient scheduling
noise; it does not guarantee success under sustained CPU contention and does not
prove a universal performance bound. A sustained ratio >= 0.7 still fails with
all samples in the error. Operation exceptions are not retried or suppressed.
The negative control is conditional on CPython with the GIL enabled; timing
checks retain the existing single-core skip. No wider threshold was introduced.
